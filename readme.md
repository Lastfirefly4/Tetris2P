七海千秋的处刑回天
Tetris Nanami – Execution Escape

一款融合了经典俄罗斯方块与平台生存元素的另类游戏。你将同时操控下落方块与像素少女“七海千秋”，在堆积的方块中生存、收集能量、躲避处刑，直到达成胜利条件。

🎮 游戏简介
在绝望的处刑游戏中，七海千秋必须一边用方块消除来维持局面，一边在方块构成的迷宫中移动、跳跃，为火箭收集 ROCKET FUEL 燃料。方块会不断下落，挤压生存空间，氧气也会逐渐耗尽，而黑白熊（Monokuma）就在一旁监视着你的挣扎。你的目标是在窒息或压死之前，把燃料充满 100 点，触发逃脱结局。

游戏包含：

标准俄罗斯方块玩法（10×15 网格）

可自由移动的 2D 角色（带二段跳、奔跑、跳跃动画）

特殊方块（加速、失控）增加策略性

ROCKET FUEL 充能系统与镜像道具

氧气、挤压、窒息等生存压力

会随局势切换表情的黑白熊 Boss（Monokuma）

🧩 核心机制
方块系统
采用 7 种标准方块（I、O、T、S、Z、J、L），使用 7-bag 随机生成器，保证公平性。

方块每次出现有概率获得特殊状态：

加速（10%）：下落速度提升一倍。

失控（5%）：无法左右移动或旋转，但下落更快。

旋转：支持顺时针旋转，并带有 墙踢（Wall Kick） 偏移尝试（-1, +1, -2, +2 列），使旋转更灵活。

镜像能力：按 X 可左右翻转当前方块，消耗 1 次镜像充能（初始 1 次，最多 3 次）。

角色（七海千秋）
占据 2 格高度，可在方块形成的平台上行走、跳跃。

移动：左右移动有惯性间隔，空中移动速度较慢。

跳跃：

普通跳跃高度 1.5 格。

二段跳（空中再次按 W）高度 1.0 格，冷却时间 5 秒（界面有圆形冷却指示器）。

生存状态：

挤压：若下落方块压到角色头部，立刻死亡，游戏结束。

窒息：若角色被方块完全包围（无通路连通外部），氧气条开始下降，持续 30 秒后死亡（氧气条会逐渐变红并闪烁）。

摔落：若角色下方无支撑物，会自然下落，落到方块或底板上。

能量与道具（ROCKET FUEL）
能量球：随机在方块空隙中生成（通常靠近当前方块堆叠顶部）。拾取后为火箭补充 ROCKET FUEL（10 或 20 点），HUD 右侧以竖向充能柱显示进度，充满 100 点即可启动逃脱结局。

镜像道具：每 30 秒在空闲格子中生成一个金色道具，拾取后增加 1 次镜像充能（初始 1 次，上限 3 次）。

道具和能量球均有一定存在时间（20 秒），超时会消失。

黑白熊 Boss（Monokuma）
HUD 面板下方会实时展示黑白熊 Boss，表情会随局势自动切换：

窒息倒计时中：嘲笑（bear_laugh）。

燃料 ≥ 75%：恐惧（bear_fear）。

燃料 ≥ 50%：愤怒（bear_angry）。

其他情况：默认残忍（bear_cruel）。

消除与反馈
当一行被填满时，该行消除，得分增加（每行 10 分，消除多行分数累加）。

消除后，上方的方块整体下移，角色若处于被消除行上方，会随之下移（避免悬空）。

每次方块锁定（落底）也会增加 1 分，并播放音效。

🏆 胜利与失败
胜利：ROCKET FUEL 充满 100 点 → 触发逃脱结局，显示胜利画面。

失败条件：

方块堆叠到达顶部（新方块无法生成）。

角色被方块挤压或压到。

氧气耗尽（窒息 30 秒）。

上述任一情况发生会进入失败画面：背景音乐立即停止，并紧接着播放一次失败音效（fail.wav）；按 Enter/R 重新开始或按 Esc 返回主菜单时，该音效会随之终止。

🎨 视觉与音效
主菜单使用独立背景（资源缺失时降级为纯色），游戏内右侧 HUD 显示：分数 / 行数、氧气条、二段跳与镜像冷却 / 次数指示、ROCKET FUEL 竖向充能柱，以及会随局势切换表情的黑白熊 Boss 展示框。

角色拥有丰富的动画：

等待、左右跑、左右跳跃（逐帧动画，来自 character/ 目录）。

背景音乐与音效的音量在代码中分开预设，互不影响：

菜单音乐与游戏内音乐各自独立（主菜单约 -5 dB，游戏内约为主菜单的两成音量）。

音效包括：脚步声、跳跃、方块锁定、镜像使用、菜单点击与失败音效等。

🧰 技术细节
使用 Godot 4 引擎开发（脚本为 GDScript）。

所有代码集中在 Main.gd 中，结构清晰，包含常量、状态管理、物理模拟、渲染等。

支持输入映射（可自行在项目设置中调整）。

依赖外部资源（图片、音频），需按 res:// 路径存放。

📌 注意事项

🌐 联机模式

主菜单提供三个入口，均可用鼠标或键盘操作：

LOCAL MODE              本机双人：玩家1 控方块，玩家2 控角色
ONLINE - HOST (BLOCKS)  开房当主机，本机操作方块（玩家1），等别人加入当角色
ONLINE - JOIN (PLAYER)  加入别人的房间，操作角色（玩家2）

架构要点：

主机权威：主机完整运行对局逻辑，周期向加入方发送快照；加入方只接收快照渲染，并把按键上传给主机。

角色固定：房主是玩家1（方块），加入方是玩家2（角色）。

默认使用 UDP 端口 8910（开房时可改，最多 5 位数字）。局域网直连使用主机等待界面显示的本机 IP。

内网穿透（SakuraFrp 等）：必须在穿透客户端建立 UDP 隧道（ENet 走 UDP），把公网端口转发到本机 8910；加入方在 JOIN 界面输入 域名:公网端口，例如 frp-net.com:29778。

内置联机优化：

双方每秒互测 RTT，对局中棋盘左侧实时显示 延迟、抖动、快照频率、丢包（延迟低于 70ms 为绿，低于 180ms 为黄，更高为红）。其中 P2OUT / P2IN 行显示角色输入位图（L/R/J = 左 / 右 / 跳）：加入方看自己发出的键、房主看收到的远端键，可用于定位“按键没反应”发生在哪一段（客户端采集 → 网络 → 主机应用）。

快照按内容变化发送：状态静止不发，变化按约 30Hz 限流；方块锁定、消行、跳跃、胜负等关键事件立即补发。棋盘只在变化或每 2 秒全量校准时随包发送。

快照带序号，客户端据此去重，防止乱序或重放导致画面倒退。

加入方角色在两次权威快照间插值渲染，减少低频率下的“步进感”。

主机暂停、恢复、胜负与断线都会即时同步给加入方。

🖱️ 鼠标与文本输入

菜单操作：

主菜单单击即确认（滚轮 / 上下键仅切换选中项），也可用键盘 Enter 进入。

JOIN、开房端口、等待连接等界面均有可点击操作区，鼠标悬停时显示下划线提示。

文本输入（JOIN 地址框、端口框）：

鼠标点击可定位光标，按住左键拖动可选中文本；键盘 ← → Home End 移动光标，按住 Shift 可扩展选区。

Ctrl+V 粘贴，Ctrl+A 全选，Ctrl+C 复制，Ctrl+X 剪切；粘贴时自动过滤该框不允许的字符并限制长度（地址最长 64，端口最长 5 位）。

存在选区时输入或粘贴会覆盖选区，Backspace 与 Delete 删除选区。

🧪 开发与自动化测试

测试脚本位于项目的 test/ 目录，用 Godot 4.7 以无头模式运行：

net_smoke.gd   冒烟测试加入方，可附加参数指定主机地址与端口
运行命令：godot --headless --path Tetris_Nanami -s res://test/net_smoke.gd -- frp-net.com 29778

net_e2e2.gd    两个真实游戏实例互通，验证双向延迟、快照零丢失、棋盘同步与渲染插值
运行命令：godot --headless --path Tetris_Nanami -s res://test/net_e2e2.gd

net_input_test.gd 角色（P2）上行输入回归：真实按键 → 客户端 → 主机权威模拟 → 镜像回显（含极短点按不丢、方向键备选）
运行命令：godot --headless --path Tetris_Nanami -s res://test/net_input_test.gd

net_ui_test.gd 菜单鼠标、文本光标、选区、剪贴板逻辑单测（33 项断言）
运行命令：godot --headless --path Tetris_Nanami -s res://test/net_ui_test.gd

net_host.gd    无头开房端，配合 net_smoke.gd 做局域网或隧道联调
运行命令：godot --headless --path Tetris_Nanami -s res://test/net_host.gd
